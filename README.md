# Exploring-CyberGym
Este projeto tem como objetivo analisar e estender o ambiente de pesquisa CybORG.

# CybORG Operations Research Gym
"Um ambiente de pesquisa em segurança cibernética para treinamento e desenvolvimento de agentes de segurança, tanto humanos quanto autônomos. Oferece uma interface comum para ambientes de rede emulados, utilizando máquinas virtuais baseadas em nuvem, e ambientes de rede simulados."

## Como utilizar
Primeiro, é preciso instalar o CybORG seguindo as instruções na pasta "Cage4". Depois, basta escolher entre a interface interativa para o Cage 4 em "Interface_Cage4" ou a criação do grafo de topologia para o Cage 2 em "Grafo_Cage2". Em cada uma das pastas seguem as instruções.

## Interface Cage 4
O cenário Cage Challenge 4 é uma simulação de rede multiagente que contém 5 agentes azuis diferentes e 5 agentes vermelhos diferentes. O objetivo do desafio é treinar agentes azuis capazes de impedir ataques na rede feitos pelos vermelhos. Demais detalhes podem ser consultados em https://cage-challenge.github.io/cage-challenge-4/pages/
A interface tem como objetivo facilitar o treinamento de agentes e a compreensão do que ocorre no cenário.

## Grafo Cage 2
O cenário Cage Challenge 2 é uma simulação de rede mais simplificada em relação ao Cage 4, possuindo apenas um agente azul e um agente vermelho. O objetivo é similar ao do Cage 4: impedir o avanço dos agentes vermelhos até um serviço crítico pela criação de agentes azuis de defesa. Como o foco do projeto foi voltado para o Cage 4, essa parte fornece apenas um parser para visualizar a topologia da rede.
